## 二、开发工具存在的问题

### 2.1 前端开发工具问题

#### Vite构建工具
| 问题 | 描述 | 解决方案 |
|------|------|---------|
| 热更新失效 | 修改代码后页面不自动刷新 | 需要手动刷新浏览器或重启开发服务器 |
| 代理配置缺失 | 开发环境API请求跨域 | 需要在`vite.config.js`中配置proxy代理 |

#### Vue.js框架
| 问题 | 描述 | 解决方案 |
|------|------|---------|
| 响应式丢失 | 直接修改数组/对象可能不触发更新 | 使用`ref()`或`reactive()`包装数据 |
| 生命周期理解困难 | Composition API生命周期钩子与Options API不同 | 使用`onMounted()`、`onUnmounted()`等函数 |

#### ESLint代码检查
| 问题 | 描述 | 解决方案 |
|------|------|---------|
| 规则冲突 | 不同插件规则可能冲突 | 在`eslint.config.js`中统一配置规则 |
| 误报问题 | 某些合法代码被标记为错误 | 使用`// eslint-disable-next-line`临时禁用 |

### 2.2 后端开发工具问题

#### Flask框架
| 问题 | 描述 | 解决方案 |
|------|------|---------|
| 热重载禁用 | `use_reloader=False`导致代码修改不生效 | 每次修改后需手动重启服务 |
| 调试模式安全风险 | `debug=True`在生产环境存在安全风险 | 生产环境必须关闭调试模式 |
| 蓝图注册遗漏 | 新增API模块忘记注册到主应用 | 在`Start.py`中注册所有Blueprint |

#### SQLAlchemy ORM
| 问题 | 描述 | 解决方案 |
|------|------|---------|
| 会话管理 | 未正确关闭数据库会话导致连接泄漏 | 使用`try-finally`确保会话关闭 |
| 懒加载问题 | 关联查询可能产生N+1查询问题 | 使用`joinedload()`预加载关联数据 |

#### PyMySQL驱动
| 问题 | 描述 | 解决方案 |
|------|------|---------|
| 连接池缺失 | 每次请求创建新连接，性能较低 | 可使用`DBUtils`实现连接池 |
| 字符编码 | 未指定charset可能导致中文乱码 | 连接时指定`charset='utf8mb4'` |

### 2.3 数据库问题

#### MySQL
| 问题 | 描述 | 解决方案 |
|------|------|---------|
| 外键约束 | 删除关联数据时可能报错 | 设置`ON DELETE CASCADE`级联删除 |
| 时区问题 | 时间字段可能存在时区偏差 | 统一使用UTC时间或配置时区 |
| 连接数限制 | 高并发时连接数可能不足 | 调整`max_connections`参数 |

### 2.4 地图服务问题

#### 高德地图API
| 问题 | 描述 | 解决方案 |
|------|------|---------|
| API Key泄露 | Key暴露在前端代码中 | 使用域名白名单限制Key使用范围 |
| 加载失败 | 网络问题导致地图无法加载 | 添加加载失败提示和重试机制 |
| 坐标偏移 | GPS坐标与地图坐标存在偏移 | 使用高德坐标转换接口 |

### 2.5 开发环境问题

| 问题 | 描述 | 解决方案 |
|------|------|---------|
| 依赖版本冲突 | 不同依赖包版本不兼容 | 使用虚拟环境隔离项目依赖 |
| 跨平台兼容 | Windows/Linux路径分隔符不同 | 使用`os.path.join()`处理路径 |
| 环境变量管理 | 敏感信息硬编码在代码中 | 使用`.env`文件管理环境变量 |

#### 3.3.2 搜索相似度算法

**模糊搜索匹配：**
```javascript
function calculateSimilarity(text, keyword) {
  const textLower = text.toLowerCase();
  const keywordLower = keyword.toLowerCase();
  
  // 计算匹配比例
  let matchCount = 0;
  let lastIndex = -1;
  
  for (let i = 0; i < keywordLower.length; i++) {
    const idx = textLower.indexOf(keywordLower[i], lastIndex + 1);
    if (idx !== -1) {
      matchCount++;
      lastIndex = idx;
    }
  }
  
  // 综合评分 = 匹配比例 * 0.5 + 文本覆盖率 * 0.2 + 位置奖励
  return matchRatio * 0.5 + textCoverage * 0.2 + positionBonus;
}
```

**特点：** 支持模糊匹配、位置加权、标题优先匹配。

#### 3.3.3 地图标记渲染算法

**标记排序优先级：**
```javascript
// 排序规则：当前用户丢失物品 > 当前用户拾到物品 > 其他用户丢失物品 > 其他用户拾到物品
function getPriority(isCurrentUser, status) {
  if (isCurrentUser && status === 0) return 0;  // 最高优先级
  if (isCurrentUser && status === 1) return 1;
  if (!isCurrentUser && status === 0) return 2;
  return 3;  // 最低优先级
}
```

function parseImageUrls(image_urls) {
  if (Array.isArray(image_urls)) {
    return image_urls;
  } else if (typeof image_urls === 'string') {
    if (image_urls.startsWith('[')) {
      return JSON.parse(image_urls);  // JSON数组格式
    } else if (image_urls.includes(',')) {
      return image_urls.split(',');   // 逗号分隔格式
    } else {
      return [image_urls];            // 单个URL
    }
  }
  return [];
}
```

# 后端登录接口
@app.route('/login', methods=['POST'])
def login():
    # 1. 获取前端发送的登录数据
    email = data.get('email')
    password = data.get('password')
    
    # 2. 查询数据库验证用户
    user = User.query.filter_by(email=email).first()
    
    # 3. 密码验证（使用Werkzeug安全加密）
    if check_password_hash(user.password_hash, password):
        # 4. 返回用户标识
        return jsonify({
            'user': {
                'user_id': user.user_id,      # 用户唯一标识
                'username': user.username,    # 用户名
                'email': user.email           # 邮箱
            }
        })
```
