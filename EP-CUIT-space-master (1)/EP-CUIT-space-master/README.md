# LLT校园失物招领与位置追踪系统

> 基于 Flask + Vue3 + 高德地图 API 构建的校园失物招领与位置追踪系统

***

## 一、项目简介

LLT校园失物招领与位置追踪系统旨在为校园师生提供一个便捷的失物招领平台，支持：

- 🗺️ **地图标记**：在地图上标记失物位置
- 🔍 **物品搜索**：快速查找失物信息
- 📝 **发布认领**：发布失物信息、申请认领
- 🛠️ **报修功能**：校园设施报修管理
- 💬 **消息通知**：实时消息推送
- 📊 **管理后台**：管理员审核管理

## 四、快速开始

### 4.1 环境要求

- Python 3.8+
- Node.js 18+
- MySQL 8.0+

### 4.2 后端部署

```bash
# 进入项目目录
cd 校园失物招领与位置追踪系统

# 创建虚拟环境（首次部署）
python -m venv .venv

# 激活虚拟环境
# Windows 系统：
.venv\Scripts\activate
# macOS/Linux 系统：
# source .venv/bin/activate

# 进入后端目录
cd 后端

# 安装依赖
pip install -r init/requirements.txt

# 初始化数据库
cd init
python main.py

# 返回后端目录启动服务
cd ..
python Start.py
```

> **注意**：虚拟环境文件夹 `.venv` 位于项目根目录下，每次启动后端服务前需先激活虚拟环境。

### 4.3 前端部署

```bash
# 进入前端目录
cd 前端/lost-found

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

### 4.4 一键启动

Windows 用户可直接运行：

```bash
双击 启动.bat
```

## 七、API 接口

### 7.1 用户接口

| 方法   | 路径                   | 描述     |
| :--- | :------------------- | :----- |
| POST | `/api/auth/login`    | 用户登录   |
| POST | `/api/auth/register` | 用户注册   |
| GET  | `/api/user/profile`  | 获取用户资料 |
| PUT  | `/api/user/profile`  | 更新用户资料 |

### 7.2 地图接口

| 方法     | 路径                         | 描述     |
| :----- | :------------------------- | :----- |
| GET    | `/api/map/lost_items`      | 获取失物列表 |
| POST   | `/api/map/lost_items`      | 发布失物   |
| DELETE | `/api/map/lost_items/{id}` | 删除失物   |

### 7.3 管理员接口

| 方法   | 路径                               | 描述     |
| :--- | :------------------------------- | :----- |
| POST | `/api/admin/login`               | 管理员登录  |
| GET  | `/api/admin/claims`              | 获取认领列表 |
| POST | `/api/admin/claims/{id}/approve` | 审核认领   |
